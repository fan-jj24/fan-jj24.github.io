CAPO: Confidence Aware Preference Optimization Learning for Multilingual Preferences

Categories: Large Language Models, Reward Models

偏好优化是一种关键的后训练技术，用于将大型语言模型（LLMs）对齐到人类偏好，通常通过在排序响应对上进行微调来实现。尽管像直接偏好优化（DPO）这样的方法在英语环境中已被证明是有效的，但它们往往难以在多语言环境中稳健地泛化。我们提出了一种简单而有效的替代方法——置信度感知偏好优化（CAPO），它用基于相对奖励的动态损失缩放机制，替代了DPO对偏好对的固定处理方式。通过根据每个偏好对的置信度调整学习信号，CAPO增强了对噪声或低边际比较的鲁棒性，这在多语言文本中通常会遇到。从经验上看，CAPO在奖励准确性上至少优于现有偏好优化基线方法16%，并通过扩大不同语言中偏好响应与非偏好响应之间的差距，提高了对齐效果。

Cortex AISQL: A Production SQL Engine for Unstructured Data

Categories: Large Language Models

Snowflake 的 Cortex AISQL 是一个生产级别的 SQL 引擎，它将原生语义操作直接集成到 SQL 中。这种集成使用户能够编写声明式查询，将关系操作与语义推理相结合，从而轻松地查询结构化和非结构化数据。然而，在生产规模下实现语义操作的高效性带来了根本性的挑战。语义操作比传统 SQL 操作成本更高，具有不同的延迟和吞吐量特性，其成本和选择性在查询编译期间是未知的。此外，现有的查询引擎并未针对语义操作进行优化。AISQL 查询执行引擎通过三种创新技术解决了这些挑战，这些技术基于 Snowflake 客户的生产部署数据。首先，AI 意识查询优化将 AI 推理成本作为首要优化目标，在查询规划过程中直接推理大型语言模型（LLM）的成本，从而实现 2-8 倍的速度提升。其次，自适应模型级联通过将大多数行通过快速代理模型进行路由，而将不确定的情况升级到强大的 oracle 模型，从而降低推理成本，实现 2-6 倍的速度提升，同时保持 oracle 模型质量的 90-95%。第三，语义连接查询重写通过将连接操作重新表述为多标签分类任务，将连接操作的二次时间复杂度降低到线性，从而实现 15-70 倍的速度提升，通常还能提高预测质量。AISQL 已在 Snowflake 上投入生产，为分析、搜索和内容理解等多个领域的客户工作负载提供支持。

A Self-Improving Architecture for Dynamic Safety in Large Language Models

Categories: Large Language Models

背景：大型语言模型（LLMs）整合到核心软件系统中的速度正在加快。然而，现有的软件架构模式是静态的，当前的安全保障方法也不具备可扩展性，使系统容易受到新型对抗性威胁的攻击。

目标：设计、实现并评估一种新型软件架构，使人工智能驱动的系统能够在运行时自主且持续地调整自身的安全协议。

方法：我们提出了一种自我改进的安全框架（SISF），这是一种运行时架构，将一个未受保护、未对齐的基础大语言模型（mistralai/Mistral-7B-v0.1）与一个动态反馈回路相结合。该反馈回路包括一个用于违规检测的人工智能仲裁者（GPT-4o）和一个政策综合模块（GPT-4 Turbo），该模块能够自主生成新的、通用的安全策略（包括启发式和语义策略），以应对系统故障。

结果：我们使用包含520个提示的AdvBench数据集进行了动态学习评估。未受保护的模型在所有情况下都存在漏洞。我们的SISF从零策略开始，呈现出明显的学习曲线：检测到237次违规行为，自主生成了234条新的安全策略，并将整体攻击成功率（ASR）降低至45.58%。在随后针对520个良性提示的测试中，SISF实现了0.00%的误报率（FPR），证明了其在不损害用户实用性的情况下具备适应能力。

结论：基于自我适应原则的架构方法是一种可行且有效的AI安全策略。我们的框架展示了一条构建更加稳健、具有弹性和可扩展性的AI驱动系统的实际路径，将安全保障从静态的部署前活动转变为自动化的运行时过程。

Private-RAG: Answering Multiple Queries with LLMs while Keeping Your Data Private

Categories: Large Language Models

检索增强生成（RAG）通过在推理时从外部语料库中检索文档来增强大型语言模型（LLMs）的能力。然而，当该语料库包含敏感信息时，未受保护的RAG系统存在泄露私人信息的风险。先前的研究已为RAG引入了差分隐私（DP）保证，但这些方法仅适用于单次查询的场景，无法满足现实中的使用需求。在本文中，我们研究了更具实用性的多查询场景，并提出了两种DP-RAG算法。第一种算法MURAG利用个体隐私过滤器，使得累积的隐私损失仅取决于每个文档被检索的频率，而非总查询次数。第二种算法MURAG-ADA进一步通过私有释放查询特定的阈值，提高了实用性，从而能够更精确地选择相关文档。我们在多个LLMs和数据集上的实验表明，所提出的方法在实际的差分隐私预算（$\varepsilon\approx10$）下，可以扩展到数百次查询，同时保持有意义的实用性。

Beyond Fact Retrieval: Episodic Memory for RAG with Generative Semantic Workspaces

Categories: Large Language Models

大语言模型（LLMs）在长上下文推理方面面临根本性挑战：许多文档超出了其有限的上下文窗口，而在能够适应的文本中，模型性能会随着序列长度的增加而下降，因此需要借助外部记忆框架进行增强。当前的解决方案从基于语义嵌入的检索逐步演进到更复杂的结构化知识图表示，以提高理解和关联能力，但这些方法主要针对基于事实的检索任务，无法构建时间空间锚定的叙事表示，从而无法跟踪实体在事件序列中的演变。为弥合这一差距，我们提出了一个受神经机制启发的生成式记忆框架——生成语义工作空间（Generative Semantic Workspace，GSW），该框架能够构建结构化、可解释的动态情境表示，使LLMs能够推理动态角色、动作和时空上下文。我们的框架包括一个操作器（Operator），用于将输入观察映射到中间语义结构，以及一个协调器（Reconciler），用于将这些结构整合到一个持久的工作空间中，以确保时间、空间和逻辑的一致性。在包含从10万到100万标记长度的语料库的事件记忆基准测试（Episodic Memory Benchmark，EpBench）中，GSW的表现优于现有的基于RAG的基线方法，最高可达20%。此外，GSW在效率方面表现突出，相较于最有效的基线模型，其查询时间上下文标记减少了51%，显著降低了推理时间成本。更广泛地看，GSW为赋予LLMs类人事件记忆提供了一个具体的蓝图，为能够进行长期推理的更强大的智能体铺平了道路。

LLM Output Drift: Cross-Provider Validation & Mitigation for Financial Workflows

为了解释这一悖论，我们采用Kim等人（2025）的观点，将简单（例如简化分数）与复杂（例如发现对称性）的推理步骤视为低概率和高概率的马尔可夫转移，并通过多任务树结构马尔可夫链（TMC）形式化后训练动态。在这个可处理的模型中，预训练对应于树的扩展，而后训练对应于思维链的重新加权。我们表明，最近在实证研究中观察到的几种现象在这一框架下自然出现：（1）RLVR产生一种“挤压效应”，降低推理熵并遗忘一些正确的路径；（2）ORM/PRM的人群奖励鼓励一致性而非准确性，因此倾向于选择常见的模式；（3）某些罕见且不确定性高的推理路径由基础模型产生，负责解决困难问题实例。

这些现象共同解释了为何探索——即使局限于基础模型的推理范围——仍然是必不可少的：它保留了处理困难案例所需的罕见但关键的推理轨迹，而这些轨迹被RLVR挤压或因推理扩展而不被优先考虑。在此基础上，我们进一步表明，探索策略如拒绝简单实例和KL正则化有助于保留这些罕见的推理轨迹。实证模拟验证了我们的理论结果。

在深度强化学习（DRL）的非平稳域中，双下降（DD）悖论——即过参数化模型在插值点之后泛化性能反而提升的现象——仍鲜有研究。我们初步证明了在无模型DRL中存在双下降现象，并通过Actor-Critic框架系统地研究了不同模型容量下的这一现象。我们采用信息论度量指标——策略熵（Policy Entropy），以衡量训练过程中策略的不确定性。初步结果表明，存在一个明显的按训练周期划分的双下降曲线；策略进入第二下降区域时，策略熵出现了持续且显著的下降。这种熵值的衰减表明，过参数化实际上起到了一种隐式的正则化作用，引导策略朝着损失景观中更鲁棒、更平坦的极小值点演化。这些发现确立了双下降现象在DRL中的重要性，并提供了一种基于信息的机制，用于设计更具泛化能力、可迁移性和鲁棒性的智能体。
