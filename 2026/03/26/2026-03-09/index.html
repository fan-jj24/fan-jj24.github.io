Automating Detection and Root-Cause Analysis of Flaky Tests in Quantum Software

与经典软件系统一样，量子软件系统依赖于自动化测试。然而，它们本质上具有概率性输出，因此容易受到“量子不稳定”（quantum flakiness）的影响——即在没有代码更改的情况下，测试结果可能不一致地通过或失败。这类量子不稳定测试可能会掩盖真实的缺陷，降低开发者的生产力，然而目前用于检测和诊断此类问题的系统化工具仍十分有限。

本文提出了一种自动化流程，用于在量子软件仓库中检测与不稳定测试相关的问题和拉取请求（pull requests），并支持识别其根本原因。我们的目标是扩展现有的量子不稳定测试数据集，并评估大型语言模型（LLMs）在不稳定分类和根本原因识别方面的能力。

基于对14个量子软件仓库的先前手动分析，我们利用LLMs和余弦相似度自动发现更多的不稳定测试用例。我们进一步评估了来自OpenAI GPT、Meta LLaMA、Google Gemini和Anthropic Claude套件中多种LLMs，以对问题描述和代码上下文进行不稳定分类和根本原因识别。分类性能使用标准性能指标进行评估，包括F1分数。

通过我们的自动化流程，我们发现了25个之前未知的不稳定测试用例，使原始数据集的大小增加了54%。表现最佳的模型Google Gemini在不稳定检测方面的F1得分为0.9420，在根本原因识别方面的F1得分为0.9643，这表明LLMs可以为量子软件中不稳定报告的分类和根本原因的理解提供实用支持。

扩展后的数据集和自动化流程为量子软件工程社区提供了可复用的成果。未来的工作将集中在提高检测的鲁棒性，并探索量子不稳定测试的自动修复。

The Missing Memory Hierarchy: Demand Paging for LLM Context Windows

大型语言模型（LLM）的上下文窗口并不是内存。它更像是L1缓存：一种小而快、成本高昂的资源，该领域将其视为整个内存系统。不存在L2缓存，没有虚拟内存，也没有页面置换。每个工具定义、每个系统提示以及每个过期的工具结果都会在会话期间占用上下文空间。其结果是可衡量的：在857个生产会话和445万个有效输入标记中，21.8%的资源属于结构性浪费。

我们提出了Pichay，这是一个为LLM上下文窗口设计的按需分页系统。Pichay以客户端和推理API之间的透明代理形式实现，拦截消息流以清除过期内容，在模型重新请求被清除的内容时检测页面错误，并根据错误历史记录固定工作集页面。在对140万次模拟清除的离线重放中，错误率仅为0.0254%。在实际生产部署中，经过681次会话，该系统可将上下文消耗减少高达93%（从5038KB减少到339KB）；在极端持续压力下，系统仍能保持运行，但会出现预期的颠簸（thrashing）现象，即被清除内容的反复加载。

关键观察是，该领域所面临的问题（如上下文限制、注意力退化、成本扩展、跨会话状态丢失等），本质上都是虚拟内存问题，只是表现形式不同。已有解决方案：工作集理论（Denning，1968）、按需分页、基于错误驱动的替换策略，以及具有多级逐出管理的内存层次结构。我们描述了LLM系统中完整内存层次结构的架构（从L1到持久存储），报告了目前已在生产中部署的前三个层级（L1逐出、L2基于错误驱动的固定、L3模型发起的对话压缩），并识别出跨会话内存是尚未开发的前沿领域。

基于交错文本标记和离散化语音标记进行预训练的自回归语音-文本模型，在语音理解和生成方面表现出色，但与文本语言模型相比，计算效率仍显著较低，部分原因在于语音标记的序列长度远长于文本。这种模态不平衡问题导致预训练和推理过程中计算资源过度分配给语音，可能阻碍跨模态对齐，并使性能扩展速度降低几个数量级。我们引入了潜语音-文本变换器（Latent Speech-Text Transformer，简称LST），该模型将语音标记聚合为潜语音块，这些块作为更高层次的自回归单元。这种设计在语音和文本之间对齐序列建模的粒度，同时提高了计算效率。所得的潜语音块可以与文本单元对齐，从而促进跨模态知识迁移，并紧凑地捕捉重复出现的声学模式（如静音）。在计算控制和数据控制的故事情节补全基准测试中，LST在提升语音准确性的同时也改善了文本性能，实现了在计算控制训练中语音HellaSwag任务上的绝对提升高达+6.5%（在数据控制训练中为+5.3%）。在接近计算最优的参数规模下，从4.2亿参数扩展到18亿参数时，性能随参数规模增长而提升，且在固定标记预算下，即使达到70亿参数，仍能保持性能提升。这些优势也扩展到了下游任务：LST稳定了语音识别（ASR）的适应过程，并在ASR和文本到语音（TTS）推理过程中减少了有效的自回归序列长度，从而降低了计算成本，而不会降低重建质量。代码可在https://github.com/facebookresearch/lst获取。

算法代理被广泛应用于各种竞争性决策场景中，包括从在线零售到住宅租赁的定价环境。我们研究了当竞争代理采用多臂老虎机算法时，算法共谋的出现情况，并将竞争建模为重复的囚徒困境博弈。值得注意的是，在我们的设定中，代理进行在线学习，事先没有游戏结构的模型，也不直接了解竞争对手的状态或行动，因此无法学习依赖这些因素的策略。尽管如此，这些无上下文的老虎机却经常表现出看似共谋的行为，我们称这种现象为“天真共谋”。我们的研究结果表明，天真共谋是否出现，很大程度上取决于老虎机学习者所采用的行为策略。共谋结果出现的机制在于代理行动的同步性，其中同步性衡量的是代理在多大程度上采取相同的行动。我们证明，当两个代理都使用一个广泛类别的持续随机算法（包括没有ε衰减的ε-贪心算法）时，长期来看，天真算法共谋永远不会出现；当两个代理都使用极限贪心算法（这些算法在探索过程中具有随机性，但渐近趋于确定性）时，天真共谋有时会出现；而当两个代理都使用确定性老虎机学习算法（如著名的上置信界（UCB）家族中的算法）时，天真共谋总是会出现。我们还强调了市场和算法条件下，人们能否事先预测共谋是否会发生。我们的研究结果具有若干政策含义：防止定价算法根据竞争对手的价格调整自身行为可能无法阻止算法共谋；算法的对称性可能会增加共谋的可能性；算法共谋的出现具有路径依赖性。

Categories: Reinforcement Learning

Categories: Reinforcement Learning

时间序列预测是金融、医疗和环境监测等应用的基础。尽管时间序列基础模型（TSFMs）取得了成功，但现有方法通常在单模态环境下运行，依赖静态提示或固定的融合方案，这限制了它们利用多模态上下文和适应实例级变化的能力。我们提出了一种参数高效的多模态框架UniCast，通过实例条件提示和动态模态路由扩展TSFMs。UniCast通过基于Transformer的上下文蒸馏器，从时间序列、视觉和文本输入中推断出条件提示，从而实现输入特定的自适应，而无需更新预测主干。为了调节辅助模态对预测的影响，UniCast采用模态路由（Modality Routing）机制，这是一种交叉注意力机制，根据当前的时间状态估计模态相关性，并选择性地增强信息性信号，同时抑制噪声。通过与冻结的TSFM结合并使用软提示调优，UniCast保留了基础层面的泛化能力，同时实现了有效的多模态控制。在多样化的预测基准测试中，UniCast在所有现有TSFM基线模型上表现一致优异，证明了实例条件的多模态控制对于下一代时间序列预测至关重要。

VLM-SubtleBench: How Far Are VLMs from Human-Level Subtle Comparative Reasoning?

Categories: Vision-Language Models

在工业异常检测、医学影像和空中监控等众多领域中，区分视觉上相似图像之间细微差异的能力至关重要。尽管近年来出现了针对视觉-语言模型（VLM）的比较推理基准测试，但它们主要关注具有明显差异的大图像，无法捕捉现实应用中所需的细致推理能力。在本研究中，我们引入了VLM-SubtleBench，这是一个专门用于评估VLM在细微比较推理能力上的基准测试。我们的基准测试涵盖了十种差异类型：属性、状态、情绪、时间、空间、存在性、数量、质量、视角和动作，并收集了反映这些细粒度差异的配对问题-图像数据集。与以往仅限于自然图像数据集的基准测试不同，我们的基准测试涵盖了包括工业、空中和医学影像在内的多种领域。通过广泛评估专有和开源的VLM，我们揭示了在不同差异类型和领域中模型与人类表现之间的系统性差距，并提供了受控分析，突出显示VLM推理能力在哪些方面急剧下降。总体而言，我们的基准测试和发现为推动VLM向人类水平的比较推理能力发展奠定了基础。

Hospitality-VQA: Decision-Oriented Informativeness Evaluation for Vision-Language Models

Categories: Vision-Language Models

近年来，视觉-语言模型（VLMs）在通用领域中展示了令人印象深刻的多模态理解能力。然而，它们在以决策为导向的领域（如旅游服务业）中的适用性仍鲜有探索。在本研究中，我们探讨了VLMs在回答与酒店和设施图像相关问题（即视觉问答，VQA）方面的表现，这些图像对于消费者的决策至关重要。虽然许多现有的VQA基准测试侧重于事实准确性，但它们很少捕捉到用户实际认为有用的信息。为了解决这一问题，我们首先引入了“信息量”这一形式化框架，用于量化图像-问题对所提供的与旅游服务业相关的有用信息量。在该框架的指导下，我们构建了一个专门针对旅游服务的VQA数据集，涵盖多种设施类型，其中问题经过专门设计，以反映用户的关键信息需求。利用该基准，我们对几种最先进的VLMs进行了实验，结果表明，VLMs本身并不具备内在的决策意识——关键的视觉信号仍被低估利用，只有在进行适度的领域特定微调后，才能产生可靠的“信息量”推理能力。

Semantic Level of Detail: Multi-Scale Knowledge Representation via Heat Kernel Diffusion on Hyperbolic Manifolds

Categories: World Models

人工智能记忆系统越来越多地将知识组织成图结构——知识图谱、实体关系、社区层次结构——但缺乏一种原理性的机制来进行连续的分辨率控制：抽象层级之间的定性边界在哪里，智能体应如何在这些边界之间进行导航？我们引入了语义细节层次（Semantic Level of Detail，SLoD），这是一个通过在庞加莱球 $\mathbb{B}^d$ 上进行热核扩散定义连续缩放操作的框架，从而回答这两个问题。在粗粒度尺度（$σ\to \infty$）下，扩散会将嵌入聚合为高层次的摘要；在细粒度尺度（$σ\to 0$）下，局部语义细节得以保留。我们证明了在Sarkar嵌入下，对于树状结构的层次，具有有界近似误差 $O(σ)$ 和 $(1+\varepsilon)$ 扭曲的层次一致性。关键的是，我们展示了图拉普拉斯算子中的谱隙会诱导出涌现的尺度边界——即表示发生定性转变的尺度——这些边界可以在无需人工设定分辨率参数的情况下自动检测。在合成层次结构（HSBM）上，我们的边界扫描器能够恢复植入的层次，其调整互信息（ARI）可达1.00，且在信息论意义上的Kesten-Stigum阈值附近，检测性能能优雅地退化。在完整的WordNet名词层次结构（82K同义词集）上，检测到的边界与真实的分类深度（$τ= 0.79$）一致，这表明该方法无需监督即可在现实世界知识图谱中发现有意义的抽象层次。

Integrating a Causal Foundation Model into a Prescriptive Maintenance Framework for Optimising Production-Line OEE

Categories: World Models

制造业向基于预测的维护（PsM）的转变在很大程度上受到对预测模型依赖性的制约。这类纯粹的预测模型往往只捕捉数据中的统计关联，而无法识别导致故障的潜在因果驱动因素，这可能导致昂贵的误诊和无效的应对措施。这一根本性限制带来了关键挑战：虽然我们可以预测故障可能发生，但我们缺乏系统的方法来理解故障为何会发生。本文提出了一种基于因果机器学习的模型，以弥合这一差距。我们的目标是超越诊断，通过模拟和评估潜在的修复方案，优化诸如整体设备效率（OEE）等关键绩效指标（KPI）。为此，我们使用了一个预训练的因果基础模型作为“假设情景”模拟器，以估计潜在修复方案的效果。通过估计每个干预措施对系统级KPI的因果效应，可以向生产线推荐具体的行动方案。这有助于识别合理的根本原因并量化其操作影响。该模型使用半合成制造数据进行评估，并与非因果和因果基准机器学习模型进行比较。本文为以人为中心的方法提供了技术基础，使工程师能够在因果环境中测试潜在解决方案，从而做出更有效的运营决策并减少昂贵的停机时间。

Neural delay differential equations: learning non-Markovian closures for partially known dynamical systems

Categories: World Models

近年来，从数据中学习动态系统的方法取得了显著进展，展现出巨大潜力。然而，许多现有方法假设可以获取系统的完整状态——这一假设在实践中很少能满足，因为系统通常是通过有限数量的传感器进行监测的，从而导致部分可观测性。为了解决这一挑战，我们受到 Mori-Zwanzig 格式启发，该格式提供了隐藏变量与记忆项之间的理论联系。基于这一视角，我们引入了一种具有固定延迟的神经延迟微分方程（Neural Delay Differential Equations, NDDEs）框架，从而提供了一种连续时间方法，直接从数据中学习非马尔可夫动态。这些记忆效应通过一组有限的时间延迟来捕捉，而这些延迟则通过伴随方法进行识别。我们在多种数据集上验证了所提出的方法，包括合成系统、混沌动态和实验测量，例如 Kuramoto-Sivashinsky 方程和腔流实验。结果表明，NDDEs 在部分可观测系统中相较于现有方法（如长短期记忆网络 LSTM 和增强神经常微分方程 ANODEs）具有明显优势。总体而言，NDDEs 提供了一种原理性强且数据高效的框架，用于在部分可观测性条件下建模非马尔可夫动态。本文附带了一个开源实现。

Opponent State Inference Under Partial Observability: An HMM-POMDP Framework for 2026 Formula 1 Energy Strategy

Categories: World Models, Reinforcement Learning

2026年一级方程式（F1）技术规则引入了能源策略的根本性变化：在内燃机与电池功率各占50%、无再生能量限制、且由车手控制的“覆盖模式”（以下简称MOM）条件下，最佳的能源部署策略不仅取决于车手自身的状态，还取决于对手车辆的隐藏状态。这种情形构成了一个部分可观测随机博弈（Partially Observable Stochastic Game），无法通过单智能体优化方法求解。我们提出了一种可处理的双层推理与决策框架。第一层是一个包含30种状态的隐马尔可夫模型（HMM），从五个公开的可观察遥测信号中推断出每个对手的ERS（能量回收系统）充电水平、覆盖模式状态以及轮胎退化状态的概率分布。第二层是一个深度Q网络（DQN）策略，以HMM的信念状态为输入，并在多种能量部署策略之间进行选择。我们正式定义了“反收割陷阱”——这是一种欺骗性策略，车辆故意压制可观察的部署信号，诱导对手陷入失败的攻击。我们证明，检测这种陷阱需要基于信念状态的推理，而不是基于反应阈值规则。在基于模型自身假设生成的合成比赛中，HMM实现了92.3%的ERS推理准确率（随机基线为33.3%），并以95.7%的召回率检测到反收割陷阱条件。预注册——实证验证将于2026年3月8日澳大利亚大奖赛开始。
