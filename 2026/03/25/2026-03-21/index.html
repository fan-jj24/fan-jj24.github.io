Detection of adversarial intent in Human-AI teams using LLMs

Categories: Large Language Models

大型语言模型（LLMs）越来越多地被部署在人类与人工智能团队中，作为信息检索、编程和决策辅助等复杂任务的支持代理。虽然这些代理的自主性和上下文知识使它们具有实用性，但也使它们面临各种攻击，包括数据中毒、提示注入，甚至提示工程。通过这些攻击途径，恶意行为者可以操控LLM代理提供有害信息，进而可能操控人类代理做出有害决策。尽管以往的研究主要将LLM作为攻击目标或对抗性行为者，本文则研究其在混合人类-人工智能团队中作为防御性监督者的潜在作用。我们使用一个包含真实人类-人工智能团队在25轮时间范围内进行的多方对话和决策的数据集，从交互轨迹中提出了恶意行为检测问题。我们发现，LLM能够在实时中识别恶意行为，且无需任务特定信息，这表明任务无关防御具有潜力。此外，我们发现，感兴趣的恶意行为难以通过简单的启发式方法识别，进一步表明引入LLM防御者可以增强人类团队对某些类别的攻击的鲁棒性。

AC4A: Access Control for Agents

在本文中，我们介绍了AC4A，这是一个面向代理的访问控制框架。随着代理变得越来越强大和自主，用户需要一种方式来限制这些代理可以访问的API或网页内容的某些部分，从而无需完全信任代理拥有API或网页所允许的所有功能。我们的目标是通过AC4A提供一个定义权限的框架，使代理只能访问其被授权访问的资源。AC4A适用于基于API的代理和基于浏览器的代理。它不规定权限的具体内容，而是提供一种灵活的方式来定义和执行权限，使其适用于实际系统。

AC4A通过创建权限来授予对资源的访问权限，其灵感来源于已有的访问控制框架，例如Unix文件系统的访问控制机制。应用程序将资源定义为层次结构，并提供一种在运行时计算访问所需权限的方法，以确保资源的成功访问。我们通过案例研究展示了AC4A在对现实世界API和网页实施权限控制方面的实用性。AC4A的源代码可在https://github.com/reSHARMA/AC4A获取。

RubricRAG: Towards Interpretable and Reliable LLM Evaluation via Domain Knowledge Retrieval for Rubric Generation

Semantic Sections: An Atlas-Native Feature Ontology for Obstructed Representation Spaces

Categories: Large Language Models
