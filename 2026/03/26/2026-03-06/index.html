FOR-Prompting: From Objection to Revision via an Asymmetric Prompting Protocol

Categories: Large Language Models

像链式思维（Chain of Thought, CoT）和树状思维（Tree of Thought, ToT）这样的推理协议能够组织内部的思考过程，但缺乏一种明确的外部提问机制，这种机制可以引发自我修正。我们提出了FOR-Prompting（From Objection to Revision Prompting），这是一种不对称的协议：防御者（Defender）提出答案，质疑者（Debater，即提问者）提出以问题形式表达的异议，但不直接提供解决方案；主持人（Host）可选择性地综合最终输出。在GSM8K数据集上，FOR-Prompting的准确度与CoT相当，并且在使用相同模型架构进行评估时，其性能显著优于单次提示方法。在小型开源模型（如LLaMA-3.2-1B）上，FOR-Prompting在直接提示方法的基础上取得了显著提升，并且其性能与轻量级推理基线相当，突显了其在资源有限和设备端应用中的潜力。跨模型角色互换实验进一步表明，模型的性能主要由防御者决定，这使得小型模型能够有效扮演质疑者的角色。除了结构化的数学任务，FOR-Prompting还支持开放性和多阶段任务中的细化：定性分析表明，其在探索、覆盖范围和具体性方面有所提升；一项盲测人类偏好的研究发现，在行程规划场景中，参与者更倾向于选择FOR-Prompting的输出，而非强大的大型语言模型（LLM）基线。该协议与模型无关，仅通过角色结构化的提示进行操作，无需训练、访问模型内部信息或对称地依赖强大的代理。因此，FOR-Prompting能够实现对基于异议推理的可扩展研究，并为托管和本地LLM的自动化迭代优化提供了一种实用机制。

激活引导方法能够在不重新训练的情况下，在推理时控制大型语言模型（LLM）的行为，但当前的方法面临一个根本性的权衡：样本效率高的方法无法充分捕捉来自标记示例的引导信号，而能够更好提取这些信号的方法则需要数百到数千个示例。我们引入了COLD-Steer，这是一种无需训练的框架，通过近似上下文示例上梯度下降所导致的表示变化来引导LLM的激活。我们的关键洞察是：对一小部分示例进行微调的效果可以在推理时通过不实际更新参数的方式来高效近似。我们通过两种互补的方法对这一思路进行了形式化：(i) 一种单位核近似方法，它通过针对每个示例进行归一化的梯度来直接更新激活值；(ii) 一种有限差分近似方法，无论示例数量多少，只需要两次前向传播。我们在多种引导任务和基准测试上的实验表明，COLD-Steer在使用比最佳基线少50倍的样本情况下，实现了高达95%的引导效果。COLD-Steer使得在无需大量演示数据的情况下，能够容纳多样化的观点，我们通过在多元对齐任务上的实验验证了这一点。我们的框架为实现灵活、上下文感知的模型控制开辟了新的可能性，这种控制能够通过原理性的学习动态近似，而不是专门的训练过程，来灵活应对不同损失驱动的人类偏好。

NOBLE: Accelerating Transformers with Nonlinear Low-Rank Branches

Categories: Large Language Models

MOOSEnger – a Domain-Specific AI Agent for the MOOSE Ecosystem

MOOSEnger 是一款专为多物理场面向对象仿真环境（MOOSE）定制的工具驱动型人工智能代理。MOOSE 案例通过 HIT（Heterogeneous Input Translator）格式的“.i”输入文件进行定义；由于其庞大的对象目录和严格的语法规范，初始配置和调试过程较为缓慢。MOOSEnger 提供了一种对话式工作流程，通过结合精选文档和示例的检索增强生成（RAG）技术，以及确定性、MOOSE-aware 的解析、验证和执行工具，将自然语言意图转换为可运行的输入。其核心加领域架构将可重用的代理基础设施（配置、注册表、工具调度、检索服务、持久化和评估）与一个 MOOSE 插件分离，该插件增加了基于 HIT 的解析、语法保持的输入文件摄入，以及用于输入修复和检查的领域特定工具。一个输入预检查流水线会移除隐藏的格式化痕迹，通过有限语法约束的循环修复结构不正确的 HIT，同时通过应用语法注册表的相似性搜索解决无效对象类型。随后，输入将通过与 MOOSE 运行时在循环中进行的验证和可选的烟雾测试（smoke test），借助基于 MCP（Multi-Component Processing）的执行后端（具有本地回退机制），将求解器诊断信息转化为迭代式的验证与修正更新。内置的评估报告会提供 RAG 指标（忠实度、相关性、上下文精确度/召回率）以及实际执行的端到端成功情况。在涵盖扩散、瞬态热传导、固体力学、多孔流、不可压缩 Navier-Stokes、相场和塑性等领域的 125 个提示基准测试中，MOOSEnger 达到了 0.90 的执行通过率，远高于仅依赖大型语言模型（LLM）基线的 0.06。

Safe Transformer: An Explicit Safety Bit For Interpretable And Controllable Alignment

Categories: Large Language Models

当前的安全对齐方法将安全行为隐式地编码在模型参数中，从而造成根本性的不透明性：我们无法轻易检查模型为何拒绝一个请求，也无法在模型的安全判断失败时进行干预。我们提出了Safe Transformer，这是一种模块化方法，通过在Transformer层之间插入一个包含显式安全位的离散信息瓶颈，来增强预训练语言模型。安全位既作为模型安全分类的可解释信号，又作为可控的开关：通过对比训练，模型学习到解耦的表示，其中安全位控制行为模式——当$s=1$时生成有帮助的响应，当$s=0$时拒绝请求；而额外的无监督位$u$则编码语义内容以进行生成。信息瓶颈中的额外无监督位允许语义信息流动，从而保留模型的生成能力。这种设计实现了可解释性（安全决策可以直接读取）和可控性（安全位可以手动覆盖），仅需轻量级微调，而无需从头开始进行预训练。在红队基准测试中，Safe Transformer实现了接近零的攻击成功率，显著优于基础模型和安全微调基线。

Categories: Large Language Models

组相对策略优化（GRPO）在训练后的自回归（AR）语言模型中具有很高的效果，但将其直接应用于扩散型大语言模型（dLLMs）时，往往会引发奖励坍缩。我们识别出两个不兼容的原因。首先，GRPO依赖于由序列概率定义的重要性比率，而在dLLMs中这些比率是难以计算的，必须通过估计（例如基于ELBO或平均场似然代理）来获得，从而产生本质上噪声较大的比率。其次，标准GRPO的公式并未针对估计比率进行设计：其条件性裁剪可能被模型无关的估计噪声异常绕过，从而产生梯度尖峰；而其固定组规模归一化则在高方差比率估计下放大梯度幅度的波动。我们证明这些效应形成了一种自我强化的不稳定循环，导致策略漂移并进一步增加比率方差。为了打破这一循环，我们提出了StableDRL，这是专门针对dLLMs的GRPO重新表述方法，其采用（i）无条件裁剪以抑制异常值引起的尖峰，以及（ii）自归一化以限制更新过程在样本梯度的凸包内。我们进一步通过一种阶梯注意力机制，将StableDRL扩展到块级扩散模型中。

SEA-TS: Self-Evolving Agent for Autonomous Code Generation of Time Series Forecasting Algorithms

Categories: Reinforcement Learning

精确的时间序列预测是跨领域决策的基础，但传统的机器学习开发在新部署时面临数据稀缺、分布变化下的适应性差以及手动迭代的回报递减等问题。我们提出了时间序列算法的自进化代理（Self-Evolving Agent for Time Series Algorithms，简称 SEA-TS），这是一个通过迭代自进化循环自主生成、验证和优化预测代码的框架。我们的框架引入了三项关键创新：（1）度量优势蒙特卡洛树搜索（Metric-Advantage Monte Carlo Tree Search，简称 MA-MCTS），它用归一化的优势分数替代固定奖励，以实现更具判别性的搜索引导；（2）带有运行提示优化的代码审查，每个执行的解决方案都会经历自动审查，并通过更新提示来编码纠正模式，防止类似错误的重复发生；（3）全局可控推理，通过将每个节点与全局最优和最差解进行比较，实现跨轨迹知识的传递。我们采用 MAP-Elites 存档来实现架构的多样性。在公共的太阳能发电基准数据集上，SEA-TS 生成的代码相较 TimeMixer 减少了 40% 的平均绝对误差（MAE），超越了当前最先进的方法。在专有数据集上，SEA-TS 生成的代码在太阳能光伏预测中比人工设计的基线减少了 8.6% 的加权平均绝对百分比误差（WAPE），在居民负荷预测中减少了 7.7% 的 WAPE，并在负荷预测任务中达到 26.17% 的平均绝对百分比误差（MAPE），而 TimeMixer 的 MAPE 为 29.34%。值得注意的是，进化模型发现了新颖的架构模式，包括结合物理约束的单调衰减头、按站点学习的昼夜循环特征以及可学习的每小时偏差校正，这表明自主的机器学习工程能够生成超出人工设计的真正新颖的算法思想。

室内空气质量（IAQ）预测在保障人员健康、确保热舒适性以及支持智能建筑控制方面发挥着关键作用。然而，由于环境因素与高度动态的人类行为之间复杂的相互作用，预测二氧化碳（CO₂）和细颗粒物（PM₂.₅）等关键污染物的未来浓度仍然具有挑战性。传统数据驱动模型主要依赖于历史传感器轨迹，往往无法预测由行为引发的排放峰值或浓度的快速变化。为了解决这些局限性，我们提出了一种双流双向反馈融合框架，该框架联合建模室内环境演变以及由行为衍生的嵌入表示，以表征人类活动。所提出的架构集成了一个上下文感知的调制机制，该机制根据共享的、不断演化的融合状态，自适应地对每个流进行缩放和偏移，从而使模型能够有选择地强调行为特征或长期环境趋势。此外，我们引入了双时间尺度的时序模块，分别捕捉CO₂的渐进累积模式和PM₂.₅的短期波动。一个结合加权均方误差、峰值敏感惩罚和不确定性正则化的复合损失函数，有助于在室内条件波动的情况下实现稳健学习。在真实世界IAQ数据集上的广泛验证表明，我们的方法在性能上显著优于当前最先进的预测基线，同时提供了对实际部署在智能建筑和健康感知监测系统中至关重要的可解释性不确定性估计。
