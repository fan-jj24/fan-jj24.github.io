大型语言模型（LLMs）通过训练时的扩展实现卓越的性能，而在推理过程中进行有效的推理，测试时的扩展进一步增强了其能力。然而，随着推理复杂度的增加，现有的测试时扩展方法会受到累积历史信息的影响，这不仅浪费了计算资源，还干扰了有效的推理。为了解决这一问题，我们观察到，通过解决一系列独立且自包含的子问题，可以实现复杂的推理。这些子问题本质上是所谓的“原子问题”，具有类似于马尔可夫过程的无记忆性质。基于这一观察，我们提出了“思维原子”（Atom of Thoughts，简称\our），其中每个状态转移包括将当前问题分解为基于依赖关系的有向无环图，并对子问题进行压缩，从而形成一个与原问题答案等价的简化问题。这种答案保持性使得迭代的“分解-压缩”过程能够自然地形成有意义的马尔可夫推理过程。此外，这些原子状态可以无缝地集成到现有的测试时扩展方法中，使得\our可以作为插件增强工具，以提升推理能力。在六个基准测试中的实验表明，\our作为独立框架或插件增强工具均表现出色。值得注意的是，在HotpotQA数据集上，当应用于gpt-4o-mini时，\our实现了\textbf{80.6%}的F1分数，分别超过了o3-mini的\textbf{3.4%}和DeepSeek-R1的\textbf{10.6%}。代码可在\href{https://github.com/qixucen/atom}{https://github.com/qixucen/atom}获取。

From Illusion to Intention: Visual Rationale Learning for Vision-Language Reasoning

Categories: Vision-Language Models, Reinforcement Learning

近期在视觉-语言推理领域的进展突显了以图像进行思考的重要性，其中模型会主动地将推理过程建立在视觉证据的基础上。然而，当前主流框架将视觉操作视为可选工具，虽然能提升指标，却未能使推理过程真正扎根于视觉信息，导致图像推理效果不佳。这种差距导致了“以图像进行思考”的幻觉：模型表面上看似基于视觉信息，却依赖于上下文无关的操作，这些操作既无法提升感知能力，也无法引导推理得到正确答案。为了解决这一问题，我们将视觉操作重新定义为推理的核心基本元素，而非可选工具，我们称之为“视觉推理化”（Visual Rationalization），它类似于文本领域的“思维链”（Chain-of-Thought）。基于这一见解，我们提出了“视觉推理学习”（Visual Rationale Learning, ViRL），这是一种端到端的范式，其训练过程直接基于视觉推理过程本身。ViRL融合了三个关键要素：（1）通过真实推理过程进行过程监督；（2）通过步骤级奖励塑造实现目标对齐；（3）通过细粒度的信用分配来区分正确、冗余和错误的操作。通过确保每个操作对推理链都有实质贡献，ViRL使模型能够“为正确视觉原因得出正确答案”。仅通过端到端强化学习训练，ViRL在涵盖感知、幻觉和推理等多个基准测试中均取得了最先进的结果。本研究确立了视觉推理化作为一种任务无关、过程扎根的范式，用于构建透明、可验证和可信赖的视觉-语言模型。

我们介绍了LongCat-Flash-Omni，这是一个拥有5600亿参数的最先进开源多模态模型，擅长实时音频-视觉交互。通过采用一种受课程启发的渐进式训练策略，从简单的模态序列建模任务逐步过渡到更复杂的任务，LongCat-Flash-Omni在保持强大的单模态能力的同时，实现了全面的多模态能力。LongCat-Flash-Omni基于LongCat-Flash模型，后者采用了高性能的零计算专家的快捷连接混合专家（MoE）架构。LongCat-Flash-Omni集成了高效的多模态感知和语音重建模块。尽管其参数量巨大（5600亿参数，其中270亿参数处于激活状态），LongCat-Flash-Omni仍实现了低延迟的实时音频-视觉交互。在训练基础设施方面，我们开发了一种模态解耦并行方案，专门设计用于管理大规模多模态训练中固有的数据与模型异构性。这一创新方法通过保持超过90%的纯文本训练吞吐量，展现了卓越的效率。广泛的评估结果显示，LongCat-Flash-Omni在开源模型中实现了多模态基准测试的最先进性能。此外，它在广泛的模态特定任务中也表现出高度竞争力，包括文本、图像和视频理解，以及音频理解和生成。我们提供了模型架构设计、训练流程和数据策略的全面概述，并开源该模型，以促进社区未来的研究和开发。

Ovis-Image Technical Report

Categories: Vision-Language Models

我们引入了 Ovis-Image，一款专为高质量文本渲染优化的70亿参数文本到图像模型，能够在严格的计算约束下高效运行。该模型基于我们之前开发的 Ovis-U1 框架构建，集成了基于扩散的视觉解码器，并结合了更强的 Ovis 2.5 多模态主干网络。它采用以文本为中心的训练流程，结合大规模预训练和精心设计的后训练优化。尽管其架构较为紧凑，Ovis-Image 在文本渲染性能上已与显著更大的开源模型（如 Qwen-Image）相媲美，并且接近像 Seedream 和 GPT4o 这样的闭源系统。关键的是，该模型仍可在单块中高端 GPU 上部署，内存需求适中，从而缩小了前沿级文本渲染与实际部署之间的差距。我们的实验结果表明，结合强大的多模态主干网络和精心设计的以文本为中心的训练方案，足以实现可靠的双语文本渲染，而无需依赖超大规模或专有模型。

Leveraging Textual Compositional Reasoning for Robust Change Captioning

Categories: Vision-Language Models

变化描述旨在描述一对图像之间的变化。然而，现有方法仅依赖于视觉特征，往往无法捕捉到细微但有意义的变化，因为它们缺乏对显式结构化信息（如物体关系和组合语义）的表达能力。为了解决这一问题，我们提出了CORTEX（COmpositional Reasoning-aware TEXt-guided），一个新颖的框架，通过整合互补的文本线索来增强对变化的理解。除了捕捉像素级差异的线索，CORTEX还利用视觉语言模型（VLMs）提供的场景级文本知识，提取更丰富的图像文本信号，揭示潜在的组合推理。CORTEX包含三个关键模块：(i) 图像级变化检测器，用于识别配对图像之间的低级视觉差异；(ii) 一种具有推理感知的文本提取（RTE）模块，利用VLMs生成隐含在视觉特征中的组合推理描述；(iii) 图像-文本双对齐（ITDA）模块，用于对齐视觉和文本特征以实现细粒度的关系推理。这使得CORTEX能够对视觉和文本特征进行推理，并捕捉仅靠视觉特征难以明确的变化。

ARIAL: An Agentic Framework for Document VQA with Precise Answer Localization

Categories: Vision-Language Models, Large Language Models

文档视觉问答（VQA）要求模型不仅能够提取准确的文本答案，还需在文档图像中精确定位这些答案，这一能力对于高风险应用中的可解释性至关重要。然而，现有的系统要么在文本准确性方面表现优异但空间定位不可靠，要么为了可解释性而牺牲性能。我们提出了ARIAL（用于可解释答案定位的代理推理），这是一个模块化框架，通过基于大语言模型（LLM）的规划代理协调专门工具，实现精确的答案提取和可靠的空间定位。ARIAL将文档VQA分解为结构化的子任务：使用TrOCR进行基于OCR的文本提取、利用语义搜索进行检索增强的上下文选择、通过微调的Gemma 3-27B模型生成答案，并通过文本到区域对齐实现显式的边界框定位。这种模块化架构能够生成透明的推理轨迹，使工具级别可审计并支持独立组件的优化。我们在四个基准数据集（DocVQA、FUNSD、CORD和SROIE）上对ARIAL进行了评估，使用文本准确性（ANLS）和空间精度（IoU 0.50至0.95的mAP）进行衡量。ARIAL在所有数据集上均取得了最先进的结果：在DocVQA上达到88.7 ANLS和50.1 mAP，在FUNSD上达到90.0 ANLS和50.3 mAP，在CORD上达到85.5 ANLS和60.2 mAP，在SROIE上达到93.1 ANLS，分别在DocVQA上超越了之前最佳方法（DLaVA）2.8 ANLS和3.9 mAP。我们的工作展示了如何通过专门工具的代理协调同时提升性能和可解释性，为构建可信、可解释的文档AI系统提供了一条途径。

VLMs have Tunnel Vision: Evaluating Nonlocal Visual Reasoning in Leading VLMs

Categories: Vision-Language Models

视觉语言模型（VLMs）在复杂的视觉任务（如视觉问答和图表理解）方面表现出色，但近期的研究表明，它们在简单的感知测试中存在困难。我们对视觉语言模型在非局部视觉推理能力方面的表现进行了评估：这种推理需要从图像中多个可能相距较远的区域收集证据，并进行串联推理。我们识别出三种不同的非局部视觉形式：比较感知，需要在工作记忆中保持两个图像并进行比较；扫视搜索，需要进行离散的、基于证据的跳跃以定位连续的目标；以及平滑视觉搜索，涉及沿着连续轮廓进行追踪。即使是一些在先前基础视觉基准测试中表现优异的旗舰模型（如GPT-5、Gemini 2.5 Pro、Claude Sonnet 4），在这些测试中也表现不佳，在人类看来简单的任务变体中，其准确率仅略高于随机水平。我们的结构化评估套件使我们能够测试VLMs是否能够执行与人类使用的视觉算法相似的视觉任务。我们的研究结果表明，尽管在原始视觉敏锐度方面有所提升，但当前模型仍缺乏核心的视觉推理能力。

World Models

Thinking by Doing: Building Efficient World Model Reasoning in LLMs via Multi-turn Interaction

Categories: World Models, Large Language Models, Reinforcement Learning

构建强大的世界模型推理能力对于大型语言模型（LLM）代理在复杂环境中进行规划和交互至关重要。虽然多轮交互可以通过真实的反馈实现对环境动态的更深入理解，但当前的方法往往强制采用一种僵化的推理过程，这限制了模型的主动学习能力，最终阻碍了高效的世界模型推理。为了解决这些问题，我们通过高效交互与主动推理（WMAct）探索世界模型的内化，使模型摆脱结构化推理的束缚，使其能够通过自身的行动直接塑造思维，并借助两种关键机制实现高效且有效世界模型推理：(1) 一种奖励重标机制，根据动作效果调整结果奖励，以激励减少冗余并实现有针对性的交互；(2) 一种交互频率退火策略，逐步减少允许的最大交互轮次，迫使模型压缩其学习过程，内化环境动态，而非过度依赖环境线索。我们在Sokoban、Maze和Taxi环境上的实验表明，WMAct能够实现有效的世界模型推理，能够解决之前需要多轮交互才能完成的任务，并且在复杂环境中展现出强大的迁移能力，从而提升了多种推理基准测试中的表现。

Uncovering Zero-Shot Generalization Gaps in Time-Series Foundation Models Using Real-World Videos

Categories: World Models

近期关于时间序列基础模型（TSFMs）的研究强调了现实世界数据的稀缺性，现有的数据集中往往通过合成数据进行补充，但其泛化能力仍存在争议。因此，在本研究中，我们提出了一种新的基准测试方法：特别是，我们旨在构建一个反映现实世界物理时序动态的精选数据集，通过光流技术从现实世界的视频中提取时序信号。为此，我们引入了REAL-V-TSFM数据集，这是一个专门设计用于捕捉来自现实世界视频的丰富且多样的时间序列的数据集。在最先进的TSFMs上进行的零样本预测实验表明，尽管这些模型在传统基准测试中表现出色，但在我们提出的REAL-V-TSFM数据集上却出现了性能下降，这表明它们对新数据集的泛化能力有限。这些发现突显了获取时间序列数据的新方法的重要性，同时揭示了近期TSFMs在通用性方面的不足，并进一步验证了我们基于视频的时间序列数据提取流程的有效性。

High-Resolution Probabilistic Data-Driven Weather Modeling with a Stretched-Grid

Categories: World Models

我们提出了一种概率性的数据驱动型天气模型，该模型能够提供任意预测长度和预测集合规模下，87个变量的高空间分辨率的集合实现。该模型采用拉伸网格结构，对感兴趣区域采用2.5公里的分辨率，而在其他区域则采用31公里的分辨率。该模型基于随机编码器-解码器架构进行训练，其损失函数基于在实际空间和频谱空间中逐点计算的连续概率等级评分（CRPS）。结果表明，频谱损失成分对于生成空间上连贯的场至关重要。该模型与MetCoOp集合预测系统（MEPS）提供的高分辨率业务数值天气预报进行了比较，结果显示其在与地表气象站观测数据进行对比时，具有竞争力的预测性能。与基于均方误差和基于CRPS但不包含频谱成分的损失函数的模型相比，该模型生成的场在空间上更加连贯。

Point3R: Streaming 3D Reconstruction with Explicit Spatial Pointer Memory

Categories: World Models

从有序序列或无序图像集合中进行密集的三维场景重建，是将计算机视觉研究应用于实际场景中的关键步骤。受DUSt3R方法的启发，该方法通过统一图像对到一个共享坐标系中，后续方法则维持一个隐式的记忆机制，以实现从更多图像中进行密集的三维重建。然而，这种隐式记忆机制在容量上存在限制，可能会导致早期帧的信息丢失。为此，我们提出了Point3R，这是一个面向密集流式三维重建的在线框架。具体而言，我们维护一个与当前场景三维结构直接相关的显式空间指针记忆。该记忆中的每个指针都分配一个特定的三维位置，并在全局坐标系中聚合附近场景信息，形成一个动态的空间特征。从最新帧中提取的信息与该指针记忆进行显式交互，从而将当前观测结果密集地整合到全局坐标系中。我们设计了一种三维层次化位置嵌入，以促进这种交互，并设计了一种简单而有效的融合机制，以确保我们的指针记忆具有统一性和高效性。我们的方法在多种任务上实现了具有竞争力或最先进的性能，且训练成本较低。代码：https://github.com/YkiWu/Point3R。
