Memory Mosaics at scale

记忆马赛克 [Zhang 等人，2025] 是一种关联记忆网络，已在中等规模网络（如 GPT-2 规模）和合成的小数据集上展现出吸引人的组合学习和上下文学习能力。本研究证明，当我们将记忆马赛克扩展到大型语言模型规模（如 llama-8B 规模）和真实世界数据集时，这些优良特性依然保持不变。

为此，我们将记忆马赛克扩展到 100 亿参数规模，使用了一万亿个 token 进行训练，引入了一些架构上的改进（“记忆马赛克 v2”），并在三个评估维度上对其能力进行了评估：训练知识存储、新知识存储和上下文学习。

在整个评估过程中，记忆马赛克 v2 在学习训练知识（第一个维度）方面与 Transformer 相当，并在推理过程中执行新任务（第二个和第三个维度）方面显著优于 Transformer。这些改进无法通过简单地增加 Transformer 的训练数据来轻松复制。即使只使用一万亿个 token 训练的记忆马赛克 v2，其在这些任务上的表现仍优于使用八万亿个 token 训练的 Transformer。

Retrieval-Augmented Generation-based Relation Extraction

Categories: Large Language Models

信息抽取（Information Extraction，IE）是一种转变过程，通过采用实体和关系抽取（Relation Extraction，RE）方法，将非结构化的文本数据转换为结构化格式。在这一框架中，识别实体对之间的关系起着至关重要的作用。尽管存在多种关系抽取技术，但它们的效果严重依赖于获取带标签的数据和大量的计算资源。为了解决这些挑战，大型语言模型（Large Language Models，LLMs）成为有前景的解决方案；然而，由于其自身的训练数据，它们可能会产生幻觉式的回答。为克服这些限制，本文提出了基于检索增强生成（Retrieved-Augmented Generation）的关系抽取方法（RAG4RE），为提升关系抽取任务的性能提供了一条路径。

本研究利用不同的大型语言模型评估了我们提出的RAG4RE方法的有效性。通过使用诸如TACRED、TACREV、Re-TACRED和SemEval关系抽取数据集等已有的基准数据集，我们的目标是全面评估RAG4RE方法的效果。特别地，我们在研究中采用了包括Flan T5、Llama2和Mistral在内的主流大型语言模型。研究结果表明，我们的RAG4RE方法在仅依赖大型语言模型的传统关系抽取方法之上表现出更优的性能，尤其是在TACRED数据集及其变体中表现尤为明显。此外，与以往的关系抽取方法相比，我们的方法在TACRED和TACREV数据集上均展现出显著的性能优势，凸显了其有效性及其在自然语言处理中推进关系抽取任务的潜力。

AgentFold: Long-Horizon Web Agents with Proactive Context Management

Categories: Large Language Models

基于大语言模型（LLM）的网络代理在信息检索方面展现出巨大潜力，但在处理长期任务时却受到上下文管理中基本权衡的制约。现有的基于ReAct的代理由于累积了大量噪声和原始历史信息，导致上下文饱和；而那些在每一步都固定对完整历史进行摘要的方法则可能造成关键细节的不可逆丢失。为了解决这些问题，我们引入了AgentFold，这是一种以主动上下文管理为核心的新型代理范式，灵感来源于人类的回顾性巩固认知过程。AgentFold将上下文视为一个需要主动塑造的动态认知工作空间，而不是一个被动填充的日志。在每一步，它学习执行一种“折叠”操作，从而在多个尺度上管理其历史轨迹：它可以进行细致的压缩，以保留关键的、细粒度的细节；也可以进行深度整合，以抽象掉整个多步子任务。在主流基准测试中，我们的结果令人印象深刻：通过简单的监督微调（无需持续预训练或强化学习），我们的AgentFold-30B-A3B代理在BrowseComp上达到36.2%，在BrowseComp-ZH上达到47.3%。值得注意的是，这一表现不仅超过了或达到了规模远大于其的开源模型，如DeepSeek-V3.1-671B-A37B，还超越了领先的专有代理，例如OpenAI的o4-mini。

Dissecting Role Cognition in Medical LLMs via Neuronal Ablation

我们在这三个医疗问答数据集上测试了该框架，采用神经元消融和表示分析技术来评估推理路径的变化。我们的结果表明，角色提示并未显著提升LLMs的医疗推理能力。相反，它们主要影响表层的语言特征，没有证据表明在不同临床角色之间存在不同的推理路径或认知差异。尽管表面上有风格上的变化，但LLMs的核心决策机制在不同角色之间保持一致，这表明当前的PBRP方法未能复制现实世界医疗实践中发现的认知复杂性。这突显了医疗AI中角色扮演的局限性，并强调了需要模拟真实认知过程而非语言模仿的模型的重要性。我们已在以下仓库中发布了相关代码：https://github.com/IAAR-Shanghai/RolePlay_LLMDoctor

InteractComp: Evaluating Search Agents With Ambiguous Queries

Categories: Large Language Models, Reinforcement Learning

FunReason-MT Technical Report: Overcoming the Complexity Barrier in Multi-Turn Function Calling

Categories: Large Language Models

函数调用（Function Calling, FC）使大型语言模型（LLMs）和自主代理能够与外部工具进行交互，这是解决复杂现实问题的关键能力。随着这一能力在先进AI系统中变得越来越核心，开发和优化它所需的高质量、多轮次训练数据的重要性不言而喻。现有的数据合成方法，如随机环境采样或多代理角色扮演，不足以在现实环境中生成高质量数据。实际挑战主要体现在三个方面：针对性模型训练、工具架构的隔离以及多轮次逻辑依赖。为了解决这些结构性缺陷，我们提出了FunReason-MT，这是一个面向现实世界多轮次工具使用的新型数据合成框架。FunReason-MT通过以下三个方法解决多轮次函数调用数据中的复杂性障碍：1）环境-接口图交互（Environment-API Graph Interactions），用于收集多样且高质量的轨迹；2）高级工具-查询合成（Advanced Tool-Query Synthesis），用于简化复杂查询的构建；3）引导式迭代链（Guided Iterative Chain），用于生成复杂的推理链（Chain of Thought, CoT）。在伯克利函数调用排行榜（Berkeley Function-Calling Leaderboard, BFCLv3）上的评估表明，我们的框架具有显著优势：基于FunReason-MT生成数据的40亿参数模型在同类模型中表现最佳，优于大多数闭源模型。进一步在BFCLv4上的性能提升验证了FunReason-MT为代理学习提供了一个可靠且稳健的数据来源。

Zero-Shot Cross-Lingual Transfer using Prefix-Based Adaptation

随着像Llama和Mistral这样的新型大语言模型（LLMs）的发布，由于它们的多语言预训练能力和强大的泛化能力，零样本跨语言迁移变得越来越可行。然而，将这些仅解码器结构的LLMs适应到不同语言的新任务中仍然具有挑战性。虽然像低秩适配（LoRA）这样的参数高效微调（PeFT）技术被广泛使用，但基于前缀的技巧，如软提示调优（soft prompt tuning）、前缀调优（prefix tuning）和Llama Adapter等，却研究较少，尤其是在仅解码器模型的零样本迁移中。我们对三种基于前缀的方法进行了全面研究，这些方法用于从英语向35多种高资源和低资源语言进行零样本跨语言迁移。我们的分析进一步探讨了在不同语言家族和字符集之间的迁移，以及模型规模从1B到24B扩展的影响。使用Llama 3.1 8B模型，基于前缀的方法在Belebele基准测试中比LoRA基线方法高出最高6%。在Mistral v0.3 7B模型中也观察到了类似的性能提升。即使仅使用123万个学习参数进行前缀调优，我们在各种基准测试中都实现了稳定的性能提升。这些发现突显了基于前缀技术作为LoRA的有效且可扩展替代方案的潜力，特别是在低资源多语言环境中。

TableTime: Reformulating Time Series Classification as Training-Free Table Understanding with Large Language Models

Categories: Large Language Models

大语言模型（LLMs）在多变量时间序列分类（MTSC）中已展现出其有效性。为了在MTSC中有效利用LLMs，需要具有信息量的数据表示方法。现有基于LLMs的方法直接从LLMs的潜在空间中从头开始编码时间序列的嵌入，以对齐LLMs的语义空间。尽管这些方法有效，但我们发现它们存在三个固有的瓶颈：（1）它们难以以无损方式编码时间序列中的时序信息和通道特定信息，而这两种信息都是多变量时间序列的关键组成部分；（2）将学习到的表示空间与LLMs的语义空间对齐非常困难；（3）它们需要针对特定任务进行重新训练，这既计算成本高昂，又需要大量人力。为了解决这些不足，我们提出了TableTime，将MTSC重新表述为一个表格理解任务。具体来说，TableTime引入了以下策略：（1）将多变量时间序列转换为表格形式，从而最大限度地减少信息损失；（2）将表格时间序列表示为文本格式，以实现与LLMs语义空间的自然对齐；（3）设计一个推理框架，整合上下文文本信息、邻域辅助、多路径推理和问题分解，以增强LLMs的推理能力，实现零样本分类。在UEA档案库中选取的10个具有代表性的公开数据集上进行的大量实验验证了TableTime的优越性。

对复杂物理系统进行准确且长期的时空预测仍然是科学计算中的一个基本挑战。尽管深度学习模型作为强大的参数化近似器，已展现出显著的成功，但它们存在一个关键的限制：在长期自回归预测过程中，误差的累积往往会导致物理上不合理的伪影。这种缺陷源于其纯粹的参数化性质，难以捕捉系统内在动力学的全部约束。为了解决这一问题，我们提出了一种新颖的检索增强预测（Retrieval-Augmented Prediction, RAP）框架，这是一种结合深度网络预测能力与历史数据真实性的混合范式。RAP的核心理念是利用历史演化实例作为系统局部动力学的非参数估计。对于任何给定的状态，RAP都能高效地从大规模数据库中检索出最相似的历史类比。该类比的真正未来演化过程则作为参考目标。关键的是，这个目标并不是损失函数中的硬约束，而是作为专门的双流架构的强条件输入。它提供了强大的动态引导，引导模型的预测朝着物理上可行的轨迹发展。在气象学、湍流和火灾模拟等多个广泛基准测试中，RAP不仅超越了最先进的方法，还显著优于一个强大的仅基于类比的预测基线。更重要的是，RAP通过有效抑制长期预测过程中误差的扩散，生成了更加符合物理现实的预测结果。

Learning Individual Movement Shifts After Urban Disruptions with Social Infrastructure Reliance

Categories: World Models

在发生重大事件后，个体移动模式的变化可以揭示社区资源需求的变化。然而，预测这些变化仍然面临诸多挑战。首先，缺乏衡量个体异质性社会基础设施韧性（SIR）的指标，而SIR直接影响个体的移动模式，同时，通常用于分析的特征（如社会人口特征）往往难以大规模获取或存在局限。其次，个体移动模式与空间环境之间的复杂交互关系尚未被充分捕捉。第三，个体层面的移动数据可能在空间上较为稀疏，难以适用于传统的移动预测决策方法。本研究将个体的SIR纳入条件深度学习模型，利用大规模、稀疏的个体级数据，捕捉个体移动模式与本地空间环境之间的复杂关系。实验结果表明，将个体的SIR与空间环境纳入模型，能够增强模型预测事件后个体移动模式的能力。此外，该条件模型能够捕捉那些在事件前表现出相似移动模式但SIR不同的个体之间移动模式的差异性变化。

Neural USD: An object-centric framework for iterative editing and control

Categories: World Models

在可控生成建模领域取得了令人惊叹的进展，尤其是在过去几年中。然而，仍存在一些挑战。其中之一是精确且可迭代的对象编辑。在许多现有方法中，通过修改条件信号来编辑生成的图像（例如，改变场景中某个物体的颜色，或在保持其他元素不变的情况下更改背景）通常会导致场景中出现意想不到的全局变化。在本工作中，我们首次尝试解决上述挑战。我们受到计算机图形学领域开发的通用场景描述符（USD）标准的启发，引入了“神经通用场景描述符”或神经USD。在该框架中，我们以结构化、分层的方式表示场景和对象。这可以容纳多样化的信号，减少模型特定的约束，并实现对物体外观、几何形状和姿态的逐个控制。我们进一步采用了一种微调方法，确保上述控制信号彼此分离。我们评估了框架中的多个设计考虑因素，展示了神经USD如何实现迭代和增量的工作流程。更多信息请访问：https://escontrela.me/neural_usd
