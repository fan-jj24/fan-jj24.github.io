Density-Guided Response Optimization: Community-Grounded Alignment via Implicit Acceptance Signals

Categories: Large Language Models, Reward Models

部署在在线社区中的语言模型必须适应在社会、文化以及特定领域背景下差异化的规范。以往的对齐方法依赖于显式的偏好监督或预定义的原则，这些方法在资源充足的场景中是有效的，但排除了大多数在线社区——尤其是那些没有制度支持、标注基础设施，或围绕敏感话题组织的社区——在这些社区中，偏好获取成本高昂、存在伦理困境，或者与文化背景不一致。

我们观察到，社区已经通过其接受、参与以及允许持续存在的内容，隐式地表达了偏好。我们证明，这种接受行为在表示空间中诱导出可测量的几何结构：被接受的回应占据着连贯且高密度的区域，反映了特定社区的规范，而被拒绝的内容则落在稀疏或错位的区域中。我们将这种结构视为一种隐式偏好信号，用于对齐，并引入了一种名为“密度引导的响应优化”（Density-Guided Response Optimization, DGRO）的方法，该方法可以在不需要显式偏好标签的情况下，将语言模型对齐到社区规范。

通过使用带有标签的偏好数据，我们证明了局部密度能够恢复社区之间的成对判断，这表明几何结构编码了有意义的偏好信号。随后，我们在涵盖不同平台、主题和语言的多种社区中，应用DGRO于标注资源匮乏的场景。与监督学习和基于提示的基线方法相比，DGRO对齐的模型始终能够产生人类标注者、领域专家和基于模型的评判者所偏好的响应。我们将DGRO定位为一种实际可行的对齐方法，适用于无法获取显式偏好监督或与实际操作方式不一致的社区，并讨论从新兴接受行为中学习所带来的影响与风险。

基于大语言模型（LLM）的可解释推荐系统可以生成流畅且事实正确的解释，但这些解释仍然可能使用与用户历史偏好相冲突的属性来为推荐项进行辩护。这种偏好不一致的解释虽然逻辑上成立，但说服力不足，且通常被标准的幻觉或忠实度指标所忽视。我们正式定义了这种失败模式，并提出了PURE框架，这是一个基于“先选择后生成”范式的偏好感知推理框架。与仅优化生成过程不同，PURE还干预证据选择过程，它会选择一组紧凑的、多跳的以物品为中心的推理路径，这些路径不仅有事实依据，而且与用户偏好结构保持一致，通过用户意图、具体性和多样性来引导，从而抑制通用性和弱个性化证据。所选证据随后通过结构感知提示注入到LLM生成过程中，以保留关系约束。为了衡量偏好不一致性，我们引入了一种基于特征层面且以用户为中心的评估指标，该指标揭示了基于事实性度量所忽略的错配情况。在三个真实世界数据集上的实验表明，PURE在保持推荐准确性、解释质量和推理效率的同时，能够持续减少偏好不一致的解释和事实幻觉。这些结果表明，值得信赖的解释不仅需要事实正确，还需要与用户偏好相一致的论证。

当前大型语言模型的安全对齐面临一个核心挑战：现有的对齐技术通常优先考虑抑制有害提示的响应，却导致模型表现出过度谨慎的行为，从而错误地拒绝了无害的请求。因此，安全对齐的一个关键目标是提高安全性的同时，尽可能减少错误拒绝。在本工作中，我们引入了一种名为能量景观引导（Energy Landscape Steering，ELS）的新颖框架，该框架无需微调，通过动态的推理时干预来解决这一挑战。我们训练一个轻量级的外部能量模型（Energy-Based Model，EBM），使其对不希望的状态（如错误拒绝或越狱行为）赋予高能量，而对期望的状态（如有益响应或安全拒绝）赋予低能量。在推理过程中，EBM将语言模型（LLM）的内部激活映射到一个能量景观中，并利用能量函数的梯度实时引导隐藏状态向低能量区域移动。这种方法在不修改模型参数的情况下，动态地引导模型向期望行为发展。通过将行为控制与模型的核心知识解耦，ELS提供了一种灵活且计算高效的解决方案。在多种模型上的大量实验表明，该方法有效，将ORB-H基准测试的合规率从57.3%提高到82.6%，同时保持了基准安全性能。我们的工作建立了一种有前景的范式，用于构建同时实现高安全性和低错误拒绝率的大型语言模型。

Rethinking Code Similarity for Automated Algorithm Design with LLMs

Categories: Large Language Models

基于大型语言模型的自动化算法设计（LLM-AAD）的兴起，通过自主生成专家级算法的代码实现，彻底改变了算法开发方式。与传统的专家驱动型算法开发不同，在LLM-AAD范式中，算法的主要设计原则通常隐含在生成的代码中。因此，直接从代码评估算法相似性，区分真正的算法创新与仅仅是语法上的变化，变得尤为重要。虽然存在多种代码相似性度量方法，但它们无法捕捉到算法的相似性，因为这些方法主要关注于表面语法或输出等价性，而非底层的算法逻辑。

我们提出了BehaveSim，这是一种通过问题解决行为来衡量算法相似性的新方法。具体而言，BehaveSim将问题解决过程视为一系列中间解的序列，即所谓的“问题解决轨迹”（PSTrajs）。通过使用动态时间规整（DTW）量化PSTrajs之间的对齐程度，BehaveSim能够区分在语法或输出层面相似但逻辑不同的算法。我们在两个关键应用中展示了BehaveSim的实用性：（i）提升LLM-AAD：将BehaveSim集成到现有的LLM-AAD框架（例如FunSearch、EoH）中，可以增强行为多样性，从而在三个AAD任务上显著提升性能。（ii）算法分析：BehaveSim通过行为对生成的算法进行聚类，使得对问题解决策略的系统性分析成为可能——这对于不断增长的AI生成算法生态系统而言是一项关键工具。本工作的数据和代码已开源，地址为：https://github.com/RayZhhh/behavesim。

Categories: Vision-Language Models

统一的多模态模型最近展现出了强大的生成能力，但生成是否以及何时能提升理解能力仍不清楚。现有的基准测试缺乏对生成促进理解的具体任务的系统性探索。为此，我们引入了UniG2U-Bench，这是一个全面的基准测试，将生成到理解（G2U）评估分为7个领域和30个子任务，这些子任务需要不同程度的隐式或显式的视觉转换。对超过30个模型的广泛评估揭示了三个核心发现：1）统一模型通常在基础视觉-语言模型（VLMs）表现不佳，而“生成-然后-回答”（GtA）推理通常会比直接推理导致性能下降。2）在空间智能、视觉错觉或多轮推理等子任务中，出现了持续的提升，其中增强的空间和形状感知能力以及多步中间图像状态被证明是有益的。3）具有相似推理结构的任务和共享架构的模型表现出相关的行为，这表明生成与理解之间的耦合会在任务、预训练数据和模型架构上产生类别一致的归纳偏见。这些发现强调了需要更多样化的训练数据和新的范式，以充分发挥统一多模态建模的潜力。

实时视频解说生成为视频中的正在进行事件提供文本描述。它在体育、电子竞技和直播等领域支持无障碍访问和用户参与。解说生成涉及两个关键决策：说什么和何时说。尽管近期基于提示的多模态大语言模型（MLLMs）在内容生成方面表现出色，但它们大多忽略了时间因素。我们研究了仅使用上下文提示是否能够支持语义相关且时间恰当的实时解说生成。我们提出了两种基于提示的解码策略：1）固定间隔方法，以及2）一种新颖的基于动态间隔的解码方法，该方法根据前一语句的预估持续时间调整下一次预测的时间。这两种方法均可在无需微调的情况下实现暂停感知的生成。在日语和英语的赛车和格斗游戏数据集上的实验表明，基于动态间隔的解码方法仅通过提示即可生成更贴近人类语言时间与内容的解说。我们发布了一个多语言基准数据集、训练模型和实现方案，以支持未来关于实时视频解说生成的研究。

视觉-语言模型（VLMs）在医学影像的复杂诊断任务中展现出巨大的潜力。然而，将VLMs应用于多器官医学影像分析时，会面临两个主要挑战：（1）模态特定的视觉-语言对齐，以及（2）跨模态特征融合。在本工作中，我们提出了MedMAP，这是一种面向医学模态的预训练框架，旨在增强3D磁共振成像（MRI）中的视觉-语言表征学习。MedMAP包含一个模态感知的视觉-语言对齐阶段和一个用于多器官异常检测的微调阶段。在预训练阶段，模态感知编码器隐式地捕捉联合模态分布，并提升视觉和文本表征之间的对齐效果。随后，我们对预训练的视觉编码器进行微调（保持文本编码器冻结），以适应下游任务。为此，我们构建了MedMoM-MRI3D数据集，该数据集包含7,392对3D MRI体积与报告，涵盖十二种MRI模态和九种异常，适用于各种3D医学分析任务。在MedMoM-MRI3D上的大量实验表明，MedMAP在基于3D MRI的多器官异常检测任务中显著优于现有的VLMs。我们的代码可在https://github.com/RomantiDr/MedMAP获取。
